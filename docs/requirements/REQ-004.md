## Requirement

V1 闭环第四环节：判定「布置的任务」与「完成的作业」的对应与完成程度。

> **修正后口径（随 `CR-003`，2026-09-10）** —— 判定粒度由**逐题对齐**改为**聚合子任务（学科）级完成结论**，且判定**落聚合层**（不落事实层）。权威源 `CLARIFICATION-2026-09-10.md`，完整语义见 `REQ-010`。

- **判定单元 = 聚合子任务（学科）**（`task_group_subjects`，DATA-013）：按 subject 合并跨天的任务（布置）与照片（完成）后给出结论
- **结论 = `完成 / 部分完成 / 未完成 / 无法判断`**，并携带**依据（依据照片）+ 置信度**，而非仅"匹配/不匹配"
- **窗口级门控**：该聚合下**全部照片挂接确认后**才自动触发完成分析；未确认完则提示「待复核 N 张」
- 分析结论为**草稿**，家长确认后成为正式结论（`completion_analyses`，DATA-017）
- 匹配 / 判定失败或不完整时给出明确状态并转人工（不猜，见 REQ-008）；**手工改归属日**须执行连锁规则（见 `REQ-010` R6）
- **判定落聚合层的理由**：周末跨 3 天，实际完成可能是「周五一部分 / 周六无 / 周日一部分」等组合，而**布置可能仅其中一天上传** → 天级判定逻辑矛盾

## 验收标准

- 对某聚合（含周末 3 天）可产出**聚合子任务级**结论（完成 / 部分完成 / 未完成 / 无法判断）+ 依据照片 + 置信度
- 门控生效：存在未确认挂接时**不触发**完成分析，并提示「待复核 N 张」
- 结论为草稿，家长确认后方为正式结论
- 跨聚合改归属日时，`photo_subject_links` 挂接目标同步迁移（不产生悬挂引用）
