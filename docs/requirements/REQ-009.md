## Requirement

M001 学生档案需记录学生所在学校，以"学校基础资料"字典形式落地（全局共享只读，非学校管理域）：

- **学校字典**：字段 = 学校名称（必填）+ 学段（小学/初中/高中，默认小学，V1 起步小学）
  - **全局共享**：字典不归属家庭，不纳入家庭数据隔离（公共基础数据例外，ADR-008）
  - V1 数据经**数据库初始化 seed 预置**（预置常用中小学），提供只读查询（支持按学段/关键词过滤）供建档选择
  - **后台维护功能暂不开发**（新建/改名/停用学校等），仅预留边界，未来变更评估
- **学生档案关联**：`school_id` **必填**（创建/更新档案必须选择已预置学校，引用不存在则 422）；删除原自由文本 `school` 字段
- 档案查询结果携带学校信息（school_id / 名称 / 学段），供页面展示"学校 · 学段"
- 消费范围限 M001 档案关联；今日报告展示学校名称留待 M007 契约时实现，不扩大本次范围

## 影响分析摘要

- 影响模块：M001（本模块）；学校字典只读列表 API 挂 M001
- 消费者：H5 UI（建档下拉）；M007（报告展示学校名，M007 契约时定义）；M002~M006 无学校逻辑
- 影响数据：DATA-011（新建，公共只读）；DATA-002/`students`（`school` → `school_id` 必填，字段变更）
- 风险：seed 预置学校覆盖不足 → 建档受阻时按变更流程补录；字典全局共享引入"公共数据例外" → 已在 ADR-008 界定并限制同性质扩展
- 兼容性：M001 尚未编码，无历史数据负担；契约草案（v0.1.0）直接修订

## 验收标准（草案，待 M001 契约批准）

- 初始化后学校字典可只读查询（按学段过滤），列表返回 `school_id`/`name`/`stage`
- 创建/更新学生档案必须携带存在的 `school_id`（缺失或不存在 → 422）
- 学生档案列表/详情返回学校信息；跨家庭仍按原规则（档案归属 `family_id` 校验）
