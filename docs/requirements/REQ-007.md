## Requirement

V1 闭环最后一环：输出"今日作业综合报告"，让用户（家长/学生）看到当日完整评定结果。

> **修正后口径（随 `CR-003`，2026-09-10）** —— **「今日」＝归属日**（凌晨 4 点为界，`AT_DAY_CUTOFF`；时区 `Asia/Shanghai`）；报告按**聚合层**组织（周次分组 + 周末合并），不再是「当天 0 点~24 点」。权威源见 `REQ-010`。

- 汇总对应归属日的 M005 质量评价与 M006 教师评价，**按聚合组织展示**（每个 `belong_date` 至少一个聚合；周五~周日合并为「周末作业」；按 `week_index` 分组显示「第 N 周」）
- 报告明确表述"今日作业完成质量"语义（不上升为能力画像）；学习画像等为 V2+ 能力，V1 只预留扩展位（见 ADR-002）
- 报告含：各聚合子任务评价、六维度表现、教师评语与改进建议、重写建议（如适用）、以及必要的可追溯入口（如"无法判断"待人工确认项、**"待复核 N 张"挂接门控提示**）
- 报告可被真实用户查看，构成可验证闭环
- **配置锁定一致性**：报告读取的聚合结论须与其生成时的 `policy_version` 一致（已聚合对象不随配置变更回算）

## 验收标准

- 归属日切换正确：9/9 20:00 与 9/10 03:00 上传的作业出现在**同一份 9/9 报告**中
- 周五~周日上传的作业合并展示为「周末作业」；按 `week_index` 分组可定位「第 N 周」
- 无可确认挂接时**不产出**完成分析结论，报告显示「待复核 N 张」
- 报告展示遵守"仅代表今日完成质量"的语义约束
