## Requirement

V1 闭环第六环节：生成面向学生/家长的"AI 教师评价"与改进建议。

> **修正后口径（随 `CR-003`，2026-09-10）** —— 上游输入改为**聚合子任务（学科）级完成结论 + 六维评分**；**「可观察行为」「不贴标签」「不武断」原则不变**。权威源见 `REQ-010`。

- **评价语言必须基于可观察行为**：禁止输出"学习态度不好/敷衍/认真/懒惰/能力差"等主观标签；应转述可观察表现，例如"存在完成质量异常：多题缺少解题过程、连续漏答、后半部分书写清晰度下降"（示例出自指令 §六）
- 重要判断尽量提供：判断结果 + 判断依据 + 置信度
- **重写建议分级**：无需重写 / 建议订正 / 建议重写部分题目 / 建议重新完成本项作业；禁止仅依赖单个 AI 判断直接强制重写
- 评价与建议基于 M005 质量评价（其输入已改为**聚合子任务级结论**）生成，并遵守可追溯与"不猜"原则；**聚合子任务为 `无法判断` 时不得据此下评语结论**
- 评价的**组织单位随 CR-003 调整**：由「按任务/逐题」改为「按**聚合子任务（学科）**」组织（含周末聚合）

## 验收标准

- 输出不含"态度/能力"类主观标签，表述为可观察行为
- 重写建议落在四级分类之一，且给出依据与置信度
- 每条评价可追溯至质量评价、聚合子任务结论与 AI 调用链
- 上游为 `无法判断` 时不强行给出结论性评语
