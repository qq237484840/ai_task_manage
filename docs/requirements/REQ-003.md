## Requirement

V1 闭环第三环节：经 LLM 把**任务输入源**解析为任务草稿、把**作业照片**挂接到聚合子任务。

> **修正后口径（随 `CR-003`，2026-09-10）** —— 职责由「逐题识别结构化作答」改为「**任务布置单解析（链路 T）+ 作业照片挂接建议（链路 H）**」；**逐题结构化不再是判定载体**。权威源 `CLARIFICATION-2026-09-10.md`，完整语义见 `REQ-010`。

- **链路 T（任务解析）**：输入 = 布置单图片 / 粘贴文本（多段混排）→ 输出 = **学科子任务 + 内容项草稿**（供家长确认 / 隐式确认）
- **链路 H（作业挂接建议）**：输入 = 作业照片 → 输出 = **照片 ↔ 聚合子任务（学科）挂接建议 + 置信度**（供家长逐张复核），承载结构随 M002 契约修订确定为 N:N 关联（`photo_subject_links`）
- 两类输出均须携带**置信度**；无法可靠判断时遵循"不猜"原则，输出 `无法判断` 并转**手工路径**（见 REQ-008）
- 通过 Provider 抽象调用 AI（`app/core/ai/`：provider 抽象 + prompt 管理 + 结果 schema 校验 + 降级），不得绑定单一模型；超时 / 返回不合规 → 降级为手工
- **承载模块（已定，2026-09-10）**：`CLARIFICATION` §2.D5 将链路 T 解析归 **M001**、链路 H 挂接 / 复核 / 分析归 **M002** → **本 REQ 不再由 M003 独立承载**；`ADR-014` 决议 1：**M003 状态 → Deferred**（Module ID 保留、不撤销），其能力由 M001（链路 T）+ M002（链路 H）+ 横切 `app/core/ai/` 承载

## 影响分析摘要

- 影响模块：**M001 + M002**（`ADR-014` 决议 1 —— 链路 T 解析归 M001、链路 H 挂接 / 复核 / 分析归 M002；原 `M003` → **Deferred**）
- 依赖：M001（任务上下文）、M002（作业照片）、`app/core/ai/`（Provider 抽象 + prompt + schema 校验 + 降级，ADR-011）
- 消费者：M001（任务草稿）、M002（挂接建议）、M005（聚合子任务级完成结论的输入）
- 影响数据：DATA-014/015（内容项 / 输入源）、DATA-016（挂接）、DATA-009（AI 调用记录；可追溯链 = 输入源 → prompt 版本 → LLM 输出 → schema 校验 → 草稿）
- 风险：手写 / 图片识别质量不稳（RISK-003）；**LLM 输出不合规**（schema 校验 + 降级兜底，RISK-008）

## 验收标准

- 给定布置单图片或粘贴文本，可产出「学科子任务 + 内容项」草稿（含置信度），经家长确认后生效
- 给定作业照片，可产出「照片 ↔ 聚合子任务（学科）」挂接建议（含置信度），供逐张复核
- 每次 AI 调用记录 model / prompt_version / request_id / latency / token_usage / result / confidence / error
- 置信度不足或返回不合规时有 `无法判断` 出口 + 手工路径
