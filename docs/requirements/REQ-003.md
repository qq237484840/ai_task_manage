## Requirement

V1 闭环第三环节：把作业图片识别为可供后续匹配与评价的结构化内容。

- 通过 OCR/Vision Provider 对图片进行识别（原始图 → 预处理图 → OCR 结果 → 结构化识别内容）
- 识别输出尽量包含题号/题目内容/学生作答/解题过程等可观察要素，并携带**置信度**
- 对无法可靠识别的内容遵循"不猜"原则，允许输出"无法判断"并流转到重拍或人工确认（见 REQ-008）
- 通过 Provider 抽象调用 AI，不得绑定单一模型

## 影响分析摘要

- 影响模块：M003（本模块）
- 依赖：M002（图片数据）；AI Provider 抽象层
- 消费者：M004（匹配输入）、M005（评分输入）
- 影响数据：识别结果实体、AI 调用记录（可追溯链：原始图片→预处理→OCR→结构化）
- 风险：手写识别质量不稳（RISK-003）；结构化粒度（整页 vs 按题）影响 M004/M005

## 验收标准（草案，待确认）

- 给定合格图片可产出结构化识别结果（含题号/答案/过程要素与置信度）
- 每次 AI 调用记录 model/prompt_version/request_id/latency/token_usage/result/confidence/error
- 识别置信度不足时有"无法判断"出口
