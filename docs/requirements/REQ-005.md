## Requirement

V1 闭环第五环节：对作业完成质量进行多维评分。

- **默认评分维度与权重（必须配置化，不硬编码）**：
  - 完成度 25% / 正确度 30% / 完整度 15% / 规范度 10% / 书写质量 10% / 作业完成质量 10%
- 综合评分只代表「今日作业完成质量」，不得解释为「学习能力评分」（输出文案需约束此语义）
- 判断应尽量提供：判断结果 + 判断依据 + 置信度
- 评分规则不得散落代码（集中管理、可配置、可追溯），AI 输出与规则处理分离记录

## 验收标准（草案，待确认）

- 可对一次匹配成功的作业产出六维度分值与综合分
- 权重修改（配置）后重新计算生效且不改代码
- 各维度与综合分附判断依据与置信度；关键结论可追溯到规则/AI 输入
