## Requirement

V1 闭环第五环节：对作业完成质量进行多维评分。

> **修正后口径（随 `CR-003`，2026-09-10）** —— 输入由「逐题判定结果」改为「**聚合子任务（学科）级完成结论**」（DATA-013 / DATA-017）；**维度与权重口径不变**。权威源 `CLARIFICATION-2026-09-10.md`，完整语义见 `REQ-010`。

- **默认评分维度与权重（必须配置化，不硬编码）**：
  - 完成度 25% / 正确度 30% / 完整度 15% / 规范度 10% / 书写质量 10% / 作业完成质量 10%
- **输入（修正）** = 聚合子任务级结论（`完成 / 部分完成 / 未完成 / 无法判断`）+ **依据照片** + 置信度；**不再消费逐题判定**（`task_items` 已废弃）
- 综合评分只代表「今日作业完成质量」，不得解释为「学习能力评分」（输出文案需约束此语义）；**「今日」口径 = 归属日**（凌晨 4 点为界，`AT_DAY_CUTOFF`）
- 判断应尽量提供：判断结果 + 判断依据 + 置信度
- 评分规则不得散落代码（集中管理、可配置、可追溯）；AI 输出与规则处理分离记录；权重/维度配置项登记 `docs/CONFIGURATION.md`
- **`无法判断` 不得强行计分**（不武断底线，ADR-003 继续适用）

## 验收标准

- 可对一次聚合（含周末 3 天）的完成结论产出六维度分值与综合分
- 权重修改（配置）后重新计算生效且不改代码
- 各维度与综合分附判断依据与置信度；关键结论可追溯到聚合结论 / 依据照片 / AI 输入
- 聚合子任务为 `无法判断` 时不强行计分
