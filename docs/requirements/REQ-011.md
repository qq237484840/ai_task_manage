# REQ-011：任务详情 · AI 未识别照片的重试入口

- **REQ ID**：REQ-011
- **标题**：任务详情页「AI 未识别的照片」只读卡片 + 单张重试（大模型自动识别失败后的自助重试）
- **来源**：用户 2026-09-14 需求增补（8 轮 grill（`grill-me`），A~F 分支逐项定稿；Project Master 记录）
- **优先级**：P1（体验补齐；**不阻断**既有功能，不改变任何契约）
- **状态**：**Approved**（2026-09-14 用户逐项确认；**零契约变更 → 无需 CR**；实施任务书 `docs/agents/Task-017.md`）
- **关联模块**：M001（任务域前端：「任务详情」页）、M002（**只消费**既有接口）
- **关联 API**：**不新增** —— 复用 `API-M002-003`（`GET /photos`）与 `API-M002-007`（`GET /photos/{id}/link-suggestions?retry=true`）
- **关联数据**：只读 DATA-003 / DATA-016；**无数据模型变更**
- **关联决策**：`ADR-011`（真实三方 + Mock 降级）、`ADR-013`（聚合层）；与 `BUG-006` 修复后的语义一致（AI 失败**如实失败**，不静默兜底）
- **分期**：**第一阶段 = A2（本期）** 作业照片挂接重试入口；**第二阶段 = A1（后置）** 布置单图片 → 解析内容项（**需 CR/ACR**，见「后续」）

## Requirement

### R1 —— 任务详情页新增「AI 未识别的照片」卡片（**只读**）

- **位置**：任务详情页（`frontend/src/views/TaskDetailView.vue`），置于页面**最底部**（不打断任务本身的阅读动线）。
- **数据口径**：**该学生**的 `kind=homework` 且 `status=unassigned` 照片
  （`GET /api/v1/photos?student_id=&kind=homework&status=unassigned&page_size=50`）。
- **口径诚实声明（必须）**：卡片口径 = **学生级待识别**，**不是本任务窗口**。原因：未挂接照片在数据上**没有窗口归属**（`photos.task_id` 仅在该照片「首条挂接确认」时写入；详见 `TD-005`）。前端文案**不得**暗示「本任务的照片」。
- **展示项**：缩略图（受控取图）、状态、上传时间、质检结论。

### R2 —— 单张「重试建议」（本需求唯一的写操作）

- 按钮 → `GET /api/v1/photos/{photo_id}/link-suggestions?retry=true`（**幂等**，契约已定义）。
- **仅列 `unassigned`**：该状态才是 retry 的有效对象（`LinkService.suggest_for_photo` 遇 `has_active_link` **直接跳过**）；`suggested` 照片**不出现**在本卡片（其正确动作是采纳/驳回，属「作业」页）。
- **不提供**：批量重试、采纳/驳回、手工挂接、删除、查看原图 —— 完整处理**引导至「作业」页**。
- **防连点**：请求期间按钮 loading 且禁用。

### R3 —— 等待与超时（硬约束）

- 该请求**单独放宽 timeout 至 60s**（全局 `frontend/src/api/http.ts` 为 **15s**；真实模型单次实测 **15.6s**，全局值必然超时 → 见 `BUG-007`）。
- loading 文案：**「AI 分析中，约 15–30 秒」**。

### R4 —— 成败反馈（零契约）

- **成功**（响应 `suggestions` 非空）：提示「已生成挂接建议，请到「作业」页采纳」+ 刷新卡片（该照片随状态变为 `suggested` 而移出列表，属**预期**）。
- **失败**（响应 `suggestions` 为空）：提示「AI 未返回建议（可能暂时不可用），可稍后重试，或到「作业」页手工挂接」。
- **本期不做**「具体失败原因可见」（需 M002 暴露最近一次 AI 调用状态 → 见「后续」）。

### R5 —— 空态与上限

- 无数据：「当前没有待 AI 识别的作业照片」。
- `page_size=50`；超出提示「更多照片请到「作业」页处理」。

## 不在本需求范围（明确登记）

- **A1（布置单图片 → AI 解析内容项）** → 第二阶段；需 **CR/ACR**（M001 需受控读取 M002 图片字节 + 新增解析重试端点 + 契约修订），本期**仅登记**。
- 批量重试 / 后台异步队列 → 需 CR（`API-M002-007` 异步化）。
- 前端展示「具体 AI 失败原因」 → 需 CR。
- 照片窗口归属补齐（`TD-005`）。

## 验收标准

- 任务详情页可见「AI 未识别的照片」卡片；存在 `unassigned` 作业照片时逐张展示；无数据时显示空态。
- 单张重试在**真实三方**可用下可成功（60s 内），并提示「去作业页采纳」+ 该照片移出列表。
- AI 不可用时提示正确，且**不谎报成功**。
- **`backend/**` 零写入**；全量回归用例数不减；`vue-tsc -p tsconfig.app.json` **0 error**；`npm run build` **EXIT=0**。
- 证据**分域标注**（前端类型检查 / 构建 / 浏览器级 / API 级）。

## 关联缺陷

- **`BUG-007`**：全局 15s timeout 与「同步 AI 调用 >15s」冲突 → 现有「重试建议」在真实模型下**前端必然超时**（表现为「成功却报失败」）。本期由 `Task-017` **顺带修复**，独立留痕。
