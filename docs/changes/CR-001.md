## 变更类型

M001 **冻结契约数据面**变更（任务建模语义重构），连带 M002 契约升级（v0.1.0 → v0.2.0 → 随 CR-002 批准 v0.3.x）。

## Context / 目标

用户确认（PD-014）：**一份"作业登记单"（task）可登记多门学科内容**，学生自主登记当日作业计划，拍照后由 AI/家长把照片归属到登记单内具体学科作业（PD-015 先采后认）。M001 现状 `tasks.subject` 必填单值 + `task_items` 扁平逐题，无法表达"登记单容器 + 多学科作业段 + 同科多份区隔"，也不支持照片按学科作业段聚合（学科卡）。

## 变更范围（提案）

1. **`tasks.subject` 语义放宽**：由"必填单学科"改为"作业登记单容器语义"——`subject` 可为 `NULL`/`'mixed'` 或不填（多学科登记单），不再约束单值学科（迁移：存量任务保留原 subject，视为单一学科段）
2. **`task_items` 增加 `group_no`（学科作业段序号）**：同一学科作业段内题目 `seq` 连续；段标识 = `(task_id, subject, group_no)`；约束：段内 subject 一致、组号连续、段可空（未分组题目归默认组 0 或单段语义——M001 变更执行时收敛定稿并回填本 CR）；`reference_answer` 保留为可选**非判定基准**辅助字段（批准附带修订：随 ADR-010 定稿，判定链端到端直判、不依赖参考答案对照，原"逐题对照能力不破坏"语义作废）；`item_type` 字段保留（题型标注，不作判定分支依据）
3. **登记单创建主体扩展**：允许 student 主体创建本人档案下的登记单（ACR-001 配套）；家长可代建
4. **冻结规则语义对齐**：由"存在 M002 提交记录后题目不可改"调整为"**存在归属照片（photo.status=assigned）后题目不可改**"；M001 需提供内部接口（候选名）：`get_task_group(task_id, subject, group_no)`、`task_photo_stats(task_id)`（assigned 计数，供 M002 数量上限与 M007 完成度）
5. **查询支持**：任务/题目按 `(student_id, subject, group_no)`、按日（created_at/当日任务）检索，供 M002 归属候选、M003 识别输入、M007 报告

## 验收标准（草案）

- 登记单可含多学科作业段（同科多份可区隔）；学科卡聚合 = `(subject, group_no)` 分组正确
- 任务存在 assigned 照片后题目不可改（原"提交即冻结"回归用例同步迁移）
- 题目逐题录入不受影响；判定链按 ADR-010 端到端直判口径（参考答案不作为基准）回归；M001 回归 + 新用例全绿
