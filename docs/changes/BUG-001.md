- **影响范围**：M001 任务列表页（`frontend/src/views/TaskListView.vue`）；验收剧本第 7 条阻塞项
- **严重级别**：中（功能不可用：列表恒空且无任何提示；无数据损坏、无安全影响）

## 1. Bug 现象

打开任务列表页 → 列表为空、页面无任何错误提示。网络面板可见：

```text
GET /api/v1/tasks?page=1&page_size=100&status=&student_id=  →  422 Unprocessable Entity
```

## 2. Root Cause

| # | 原因 |
| --- | --- |
| 1 | 前端把「全部状态 / 全部学生」表达为**空字符串**并放入 query → axios 序列化为 `?status=&student_id=` |
| 2 | 后端 `backend/app/api/v1/tasks.py` 入参 `status: Literal["draft","published","in_progress","closed"] \| None` 是**严格枚举**，空串不合法 → FastAPI 请求校验 **422** |
| 3 | `TaskListView.vue` 的 `loadTasks()` 只有 `try/finally`、**无 `catch`** → 未捕获 Promise rejection；`loading` 被复位但列表无数据、无错误提示（**静默失败**） |

## 3. Fix

| # | 文件 | 改动 |
| --- | --- | --- |
| 1 | `frontend/src/api/http.ts` | 请求拦截器新增 `stripEmptyParams()`：**统一剔除 query 中的 `""` / `null` / `undefined`**（跳过 `URLSearchParams` 实例）→ 一次覆盖所有列表页，避免各页各自处理 |
| 2 | `frontend/src/views/TaskListView.vue` | 不再把空串回填为枚举值（改 `undefined`）；补 `catch (err) { toastError(err) }` |

**后端不改**：严格枚举是正确的契约表达，问题在调用侧产生非法参数。

## 4. Affected Area

`frontend/src/api/http.ts`、`frontend/src/views/TaskListView.vue`。**零 API / 数据 / 后端业务改动。**
