## 变更类型

**需求语义修正（破坏性）+ 数据模型重构**：M001/M002 已冻结/开发中的核心语义被修正，新增聚合层与 AI 接入层。

## Context / 目标

用户指出开发功能与需求存在偏差，重新澄清三条：

1. **任务**是"上传一张照片（或一段文字/聊天记录）→ 大模型分析今日任务 → 整理成子任务"，上传**无需填写内容**；命名与归类逻辑与作业一致。
2. **「照片」菜单改名「作业」**；每天作业有主表（周几 + 日期），每周按周次分组，周一到周四如实显示，**周五~周日取名为"周末作业"**；**凌晨 4 点到次日 4 点归为当天**。
3. 作业上传后家长可维护；大模型先按作业内容**自动挂接到子任务**，家长**复核后**才开始分析完成情况。

目标：把"家长手工录入的任务登记单 + 逐题判定"重构为"**按天解析的任务事实层 + 跨天聚合层（挂接与判定在此）**"。

## 变更范围

### 1. 数据模型（`DATA_MODEL.md`）

- `DATA-001` 修订：`tasks` 新增 `category`（v1 仅 `school`）/`belong_date`/`week_index`/`window_type`/`spec_status`，唯一键改为 **`(student_id, category, belong_date)`**；`title` 支持自动生成。
- `DATA-003` 修订：`photos` 增加 `kind` 冗余（`task_spec` | `homework`，由上传入口决定，权威在 `upload_batches.kind`）；`subject`/`group_no` 废弃；**归属约束由 1:N 放开为 N:N**。
- 新增 `DATA-012` `task_groups`（聚合任务，含 `policy_version`）、`DATA-013` `task_group_subjects`（**★判定单元**）、`DATA-014` `task_contents`（内容项，只读）、`DATA-015` `task_spec_sources`（多段输入源）、`DATA-016` `photo_subject_links`（N:N 挂接）、`DATA-017` `completion_analyses`（完成分析草稿/确认）、`DATA-018` `window_policies`（窗口与聚合策略配置，带生效日期）。
- **`task_items` 废弃**（逐题建模不再作为判定载体，V1 不再写入）。

### 2. 判定与挂接

- 判定粒度由 ADR-010 的**内容级逐题**改为 **聚合子任务(学科)级**（`ADR-013`，`ADR-010` 判定粒度 Superseded）；**继承**端到端直判、可观察依据、置信度、`无法判断` 出口、家长复核、不武断底线。
- 挂接 = 作业照片 ↔ 聚合子任务，**N:N**；复核单元 = **逐张照片**；完成分析 **窗口级门控**（全部确认后才分析）。
- 链路 T 解析结果需家长确认；**支持在"确认作业完成情况"时隐式确认落库**（确认页须展示将一并落库的解析摘要）。

### 3. 窗口与配置

- 新增配置：`AT_TIMEZONE`（`Asia/Shanghai`）、`AT_TERM_START`、`AT_TERM_END`、`AT_DAY_CUTOFF`（默认 `04:00`）。
- **配置锁定语义**：变更只影响**未聚合**对象；已聚合按生成时配置（`task_groups.policy_version`）；锁定**粒度** = 每个 `(学生, 聚合对象)`；锁定**触发** = 数据写入，纯浏览不锁。
- 假期：`WindowResolver` 策略化，V1 按自然周聚合；假期完成计划与报告 **V2**。

### 4. 模块与契约

- **M001（Stable）契约修订**：任务创建改为"输入源上传 → AI 解析草稿 → 确认"；`task_spec_sources`/`task_contents` 落 M001；`task_items` 相关契约条款作废。
- **M002（Developing，v0.3.0 Frozen）契约修订**：上传入口分「任务」/「作业」；作业上传**不填内容**；归属由段级 1:N 改为聚合子任务 N:N；`suggestion_json` 语义随之调整（涉 M003 注释漂移待清理）。
- **LLM 接入层**：新增 `app/core/ai/`（provider 抽象 + prompt + 结果 schema 校验 + 降级），属横切能力，不设业务模块。
- **前端**：菜单「照片」→「**作业**」；列表按周次分组 + 周末聚合展示；任务列表页 **422 缺陷修复**（验收阻塞项）。
