## 变更范围（提案）

1. **M001 题目建模**：随 ADR-010，题目保留（题号/题干/学科/题型/组），**参考答案字段不再是判定基准**（端到端直判替代对照）；CR-001 草案中"客观题参考答案逐题对照能力保留"条款改为"可选保留、不作为基准"（迁移：存量测试语义改写）
2. **M002 契约 v0.2.0 → v0.3.0（已起草，2026-09-08）**：先采后认归属保留；"完成程度=照片覆盖二值化"升级为**以内容级判定为准**（逐题完成结论由 M003/M004 链回写），M002 仍管采集/质检/归属——九件套已升 v0.3.0，签署区待用户批准
3. **M003 能力点扩充**：新增"布置单识别"（OCR 布置页 → 结构化今日作业清单草稿，供 M001 登记单确认补正）+ 原有作业照片识别（结构化逐题作答）；两类 AI 环节登记入 DATA-009/AI 环节清单
4. **M004**：输出**逐题对齐判定**（布置题 ↔ 照片作答逐题对齐：完成/未完成/无法判断 + 对/部分对/错 + 依据 + 置信度），低置信入家长复核队列（B/C 功能域衔接）
5. **M005**：消费逐题判定 → **大模型综合评判**（六维质量 + 综合分，权重仍配置化 DATA-010），基于证据出具
6. **M007**：今日报告**草稿 → 家长复核定稿 → 归档**（保留草稿与复核记录，可追溯）
7. **REQ-001~007** 措辞随本变更精校（布置登记识别、内容级判定、报告复核定稿）
8. **API/数据**：各模块 MODULE_API/MODULE_DATA 随契约轮更新；DATA-001/004/005/006 语义同步
