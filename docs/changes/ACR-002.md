## 变更类型

架构变更（AI 正确度判定策略 + AI Provider 默认实现策略），影响 M001（已 Stable，冻结面）、M003~M007 全部后续契约语义、DATA-001 判定基准语义、部署环境假设。

## Current Architecture

1. **正确度判定（ADR-006）**：分科混合 —— 客观题对照教师录入的参考答案判 `对/部分对/错`；主观题**不判对错**只评质量；参考答案缺失则不做对错判定。
2. **AI 评价边界（ADR-003）**：可观察行为、禁止主观标签、不猜原则（无法判断→人工/重拍）。
3. **Provider 接入（ADR-007）**：抽象 + **Mock 先行**（本地无 key 跑通全链路为默认运行路径），真实三方后补。
4. **完成程度（M002 v0.2.0 / PD-015）**：学科作业段照片覆盖二值化。

## Problem / Why Current Design Is Insufficient

用户核心需求③④的字面语义是：**大模型将布置作业与已完成作业内容进行匹配并判完成/对错，分析完成情况综合评判形成每日报告**。grill 定稿将口径升级为：

- **内容级匹配与评判（g2 + q2-1/q2-2）**：布置精确到题；匹配 = 照片识别内容 ↔ 布置题目**逐题对齐**并判完成/对错；**主客观全判**（主观题也判对错）；判定基准 = **模型端到端直接判**（不维护参考答案字段），模型综合题干+作答给出对错与可观察依据（数学可验算/语文可比对原文），低置信入复核。
- **六维保留但 AI 评判为核（q2-3）**：M005 = 逐题完成/对错结论 + 大模型综合评判（六维质量 + 综合分），均基于识别/匹配证据出具，权重仍配置化。
- **报告草稿→家长复核定稿（q2-4）**：M007 产出草稿报告 → 家长复核 → 定稿归档（草稿+复核记录保留）。
- **真实三方为默认运行（g3）**：Provider 抽象下真实三方（OCR/Vision/LLM）为默认实现，Mock 降级为测试桩与离线降级；部署环境需可访问三方 API（联网）。

现有架构（ADR-006 分科混合/主观不判、ADR-007 Mock 先行、完成程度二值化）无法表达上述口径。

## Proposed Architecture

1. **正确度判定策略重定义（ADR-006 → Superseded by ADR-010）**：内容级主客观全判；判定 = 端到端直判（不依赖参考答案字段），输出每题 `对/部分对/错` 或 `无法判断` + 依据 + 置信度；低置信与无法判断进入家长复核；ADR-003 不武断/可观察/不猜原则**保留**（判定对象扩至主观题，但禁止贴态度/能力标签不变）
2. **Provider 默认实现反转（ADR-007 → Superseded by ADR-011）**：真实三方 Provider 为默认运行；Mock 仅测试桩 + 离线降级（`model=mock-*` 标识）；新增联网前提、密钥/模型/限额配置、超时/重试/降级与调用审计约束
3. **内容级数据面/行为面（由 `CR-002` 承载）**：M001 题目建模调整（参考答案字段不再是判定基准）、M002 完成程度口径升级、M003 新增"布置单识别"AI 环节、M004 逐题对齐输出、M005 大模型综合评判为核、M007 报告草稿→复核定稿
4. **主线组织（`ROADMAP.md` v0.9.0）**：验收里程碑按 4 功能域（A 学生自主采集 / B 家长复核确认 / C 内容级匹配+兜底 / D 综合评判+报告定稿）重排，模块契约治理保留

## Alternatives

| 方案 | 说明 |
| --- | --- |
| A. 维持 ADR-006 分科混合 | 不贴需求④字面，主观题对错判定无法表达 |
| B. 参考答案录入 + 对照（原 ADR-006 的"客观对照"扩展至全科） | 录入负担大，布置页照片通常无答案，主观题答案难定义 |
| C. 纯 AI 端到端直判（g2 定稿采纳） | 零录入；风险=误判/争议（已用置信度门槛 + 可观察依据 + 家长复核 + 无法判断出口对冲） |
