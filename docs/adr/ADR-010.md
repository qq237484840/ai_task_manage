# ADR-010：正确度对错判定 —— 内容级主客观全判 + 端到端直判（取代 ADR-006，PD-018/PD-021/PD-022）

- **状态**：**Accepted**（2026-09-08，随 ACR-002 批准生效；ADR-006 → Superseded）
- **日期**：2026-09-08
- **决定者**：用户（grill 定稿 g2/q2-1/q2-2）+ Project Master
- **关联**：`docs/PROJECT_STATUS.md`（PD-018/021/022）、`docs/changes/ACR-002.md`、`docs/changes/CR-002.md`、`docs/DATA_MODEL.md`（DATA-001/006）、ADR-003（不武断底线保留）、`docs/ASSUMPTIONS.md`（ASM-011）

## Context

用户核心需求③④语义升级为**内容级**：布置精确到题；匹配 = 照片内容↔布置题目逐题对齐并判完成/对错；大模型综合评分。原 ADR-006（分科混合：客观题对照教师录入参考答案、主观题不判对错）被判定为不足以表达需求字面语义，且布置页照片通常没有参考答案，全科人工录答案负担高。

## Problem

内容级"判对错"以什么为基准？主观题是否也判对错？如何在可靠性风险与"需求④字面语义"之间定界？

## Options

| 方案 | 说明 |
| --- | --- |
| A. 参考答案对照（原 ADR-006 客观题方案，扩展至全科） | 布置页通常无答案，需人工全科录答案，负担高且主观题答案难定义 |
| B. **模型端到端直接判**（采用） | **不维护参考答案字段**：大模型综合题干 + 作答直接判 `对 / 部分对 / 错`，输出**可观察依据**（数学可验算 / 语文可比对原文 / 英语可对照句型词汇）+ 置信度；置信度低 → 家长复核兜底 |
| C. 维持分科混合 | 主观题不判对错，与需求④字面不符 |

## Decision

- 判定粒度 = **内容级逐题**：识别（M003）→ 与布置题逐题对齐（M004）→ 每题输出 `对 / 部分对 / 错 / 无法判断` + 依据 + 置信度（新判定基准，替代参考答案对照）
- **主客观全判**：客观题与主观题均由大模型按可观察证据判对错；主观题依据为"要点/步骤/表达对照 + 可观察描述"，禁止态度/能力标签（ADR-003 不武断底线保留，仅判定对象扩至主观题）
- **端到端直判**：任务建模**不把参考答案作为判定基准**（CR-002：M001 既有 `reference_answer` 可选字段保留为非基准辅助，判定链不依赖它）
- 无法可靠判断（识别不清/低置信/证据不足）→ `无法判断` 入**家长复核**（不猜原则保留，ADR-003），复核结论回写留痕
- 评分消费：M005 依 **q2-3/CR-002 定稿语义**（逐题完成/对错结论 + 大模型综合评判为核）+ 配置化权重（DATA-010），正确度维度=逐题判定聚合；Provider 执行层默认实现按 ADR-011（真实三方）

## Reason

- 贴近需求④字面："大模型分析完成情况 → 综合评判"，无需人工预录答案即可判
- 可靠性与追责对冲：每判必给依据 + 置信度 + 可观察表述 + `无法判断`出口 + 家长复核留痕
- 数学可验算、语文可比对原文、英语可比对句型词汇，使端到端判定具备可解释基础

## Consequences

- ADR-006（分科混合/参考答案对照）**Superseded**；RISK-002（录入负担）随之降级，RISK-003（识别判定可靠性）口径升级、复核负担（RISK-006）扩展
- M001 题目建模随 CR-002 调整（参考答案不再是基准）；M003~M007 契约轮按内容级语义设计
- 测试需覆盖：逐题对齐、主客观判定依据样例、无法判断→复核、复核回写留痕
