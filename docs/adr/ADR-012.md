# ADR-012：前端技术栈统一 —— Vue3 + Vite + TypeScript + Vant 4（移动组件库），构建产物由 FastAPI 托管（PD-025）

- **状态**：**Accepted**（2026-09-08，用户三项决策点逐项答复后生效）
- **日期**：2026-09-08
- **决定者**：用户（Q1 Vant 4 移动库 / Q2 TypeScript / Q3 独立前置任务）+ Project Master（可行性评估）
- **关联**：`docs/PROJECT_STATUS.md`（PD-025、O-6 关闭）、`docs/changes/CHANGE-002.md`、`docs/agents/Task-003.md`、`docs/ARCHITECTURE.md`（技术架构前端段）、ADR-004（技术栈形态：移动优先 H5 + FastAPI + SQLite 单体）、M001 DESIGN/FILES/SUMMARY（前端实况回填由 Task-003 执行）

## Context

ADR-004 只规定「移动优先 H5 + FastAPI 静态托管」形态，**未绑定具体前端框架**。M001 实现期（Task-001）因本机无 Node 环境，前端落地为**零构建原生 H5**（`frontend/index.html` + `styles.css` + `app.js` 431 行 DOM 模板渲染；FastAPI `StaticFiles(html=True)` 挂载，`REST API` 为唯一契约面，当时决策记录即注明「Vue3+Vite 仅作可替换壳，REST 契约不受影响」）。

随 M002~M007 前端面扩大（拍照采集、逐图质检报告、照片归属确认、家长复核、报告查看），零构建手写 DOM 的维护成本上升；跨模块开放项 O-6（两级主体前端体验）长期承载于前端任务。用户 2026-09-08 提出前端重构为 Vue3 生态，PM 完成可行性评估后逐项确认。

## Problem

将前端统一到工程化技术栈（Vue 生态），同时保持：移动优先体验（ADR-004）、FastAPI 单进程静态托管形态、REST 契约零影响、与正在编码的 Task-002（前端基础 UI 未实现）零返工衔接。

## Options（PM 可行性评估 2026-09-08）

| 维度 | 评估结论 |
| --- | --- |
| 契约影响 | **无**。REST API 是唯一契约面；M001 DESIGN 决策 1 预埋「可平滑换 Vue3+Vite 壳」 |
| 存量规模 | 极小：app.js 431 行 / styles.css 134 行 / index.html 14 行，6 视图 + 双主体导航 + 会话 |
| 切换窗口 | Task-002 前端基础 UI 尚未实现 → **当前是唯一零浪费窗口**（M002 页面直接按新栈写；若等其交付后再切，M001+M002 双前端返工） |
| 托管兼容 | FastAPI 静态挂载点与框架解耦：生产 mount 构建产物 `dist/`，单进程形态不变（ASM-010）；dev 走 Vite proxy |
| 环境缺口 | 本机无 Node/npm（与 M001 决策时点一致）→ 构建期需 Node ≥20 + npm（联网）；**运行期为静态产物，运行环境无 Node 依赖**（ASM-010 已接受联网部署） |
| 组件库取舍 | 用户点名 Element Plus；PM 提示其桌面密度与「移动优先 H5」（家长/学生手机高频操作）冲突 → **用户改选 Vant 4 纯移动组件库**（Q1 答复）；移动端拍照/上传经原生 `input capture`，不受组件库影响 |

## Decision

- **框架**：Vue 3（Composition API + `<script setup>`）；**构建**：Vite（工程化 SPA）；**语言**：TypeScript（API DTO 类型化，前后端契约对齐，多 Agent 并行降低契约偏离）
- **组件库**：**Vant 4**（移动优先，与 ADR-004 契合；放弃 Element Plus）；桌面/家长管理视图以响应式布局与卡片呈现适配
- **路由**：Vue Router 4，**hash 模式**（静态托管无需 history fallback，后端零改动）
- **HTTP**：axios + 统一封装，错误语义与 API 契约对齐（400/401/403/404/409/413/415/422）
- **状态**：Pinia（会话 / 双主体上下文 / 全局轻状态）
- **工程目录**：`frontend/` = `src/`（views/components/api/stores/router/types）+ `package.json`/`vite.config.ts`/`tsconfig*`；构建产物 `frontend/dist/`；现有零构建 `index.html`/`styles.css`/`app.js` 退役删除
- **托管与开发**：dev = Vite dev server（`/api/v1` proxy → `127.0.0.1:8000`）；prod = FastAPI `StaticFiles` mount `dist/`（挂载点沿用现有 settings.frontend_dir 语义，切换指向构建产物）；单进程形态与 ASM-010 部署不变
- **执行路径**：登记 `CHANGE-002`（变更执行）+ `Task-003`（AGENT-M001，独立前置任务）；M001 现有 6 视图 + 导航/会话功能等价迁移；**Task-002 前端基础 UI 后段接轨新栈**（后端编码不受阻，可并行）
- 本决策不改变 ADR-004/ASM-010/API 契约与任何后端数据面

## Reason

- 满足用户技术方案变更诉求（Vue3 生态），Vant 4 贴合 ADR-004「移动优先」既定目标
- 单一工程统一承载 M001~M007 全部前端（O-6 落地），避免逐模块维护零构建手写 DOM
- TypeScript + 契约驱动：API 契约单一事实源，前端类型层降低实现期契约偏离
- 静态产物托管保持 FastAPI 单进程部署形态（运行环境无需 Node）

## Consequences

- `CHANGE-002`（Executing）+ `Task-003`（AGENT-M001 Active）：Vite+Vue3+TS+Vant 工程搭建、M001 页面迁移、托管切换、Task-002 前端接轨注记、M001 DESIGN/FILES/SUMMARY 与 ARCHITECTURE 回填
- 开发/构建期需 Node ≥20（npm 联网）；CI/首次构建产生 `dist/`；README/部署说明补充构建步骤
- M003~M007 全部前端 UI 基于本工程（Vue 组件）实现；ROADMAP M-A 全量验收及后续域验收以新栈演示
- REST API 契约、后端 89 测试、数据面**零影响**（前端无自动化测试，Task-003 以功能冒烟 + 构建冒烟覆盖）
- 开放项 O-6 → 由本决策承载关闭（前端体验落统一工程；体验打磨随各模块 UI 任务推进）
