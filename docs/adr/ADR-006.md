# ADR-006：正确度对错判定 —— 分科混合策略（PD-005）

- **状态**：Accepted
- **日期**：2026-09-08
- **决定者**：用户（PD-005 确认）+ Project Master
- **关联**：`docs/PROJECT_STATUS.md`（PD-005）、REQ-005、`docs/DATA_MODEL.md`（DATA-001/006）、`docs/ASSUMPTIONS.md`（ASM-011）

## Context

六维评分中"正确度"占 30%（REQ-005）。但"AI 如何判定对错"存在多种口径：教师逐题录答案成本高；纯 AI 自判对小学生误判风险大且难追溯；且主观题（如语文作文）天然没有"对错"。该基准直接决定 M001 题目建模与 M005 评分算法（PD-005）。

## Problem

V1 正确度维度以什么为基准判定"对/错"，才能兼顾客观可解释、教师负担可控、主观题不误判？

## Options

| 方案 | 说明 |
| --- | --- |
| A. 教师录答案 + AI 对照 | 全科都要录答案，录入成本最高，主观题答案也难定义 |
| B. 纯 AI 判对错 | 零录入但误判风险高，对小学生难追溯，纠纷难解释 |
| C. **分科混合策略**（采用） | 客观题：AI 对照教师录入的参考答案判对/部分对/错；主观题：不判对错，只评完成质量，报告注明"正确度不适用" |
| D. V1 降级取消正确度 | 偏离需求权重表，需大规模重配 |

## Decision

- M001 题目建模（DATA-001）支持每题标注：**学科**、**题型（客观/主观）**、**可选参考答案**
- M005 判定规则（集中配置、版本化，不散落代码）：
  - **客观题**（如数学计算/英语等，按任务录入判定）：教师录入参考答案 → AI 依据题干+答案判定 `对 / 部分对 / 错`，附置信度；若该题参考答案缺失 → **不做对错判定**并在报告中明示
  - **主观题**（如语文作文、开放性题）：**不判对错**，只评价完成质量相关维度；正确度维度对整项作业按"可判定题目加权聚合"，不可判定部分在报告中注明"正确度不适用"
  - AI 无法可靠判断（图像不清/识别低置信）沿用 ADR-003："不猜、标记无法判断"，进入人工复核或重拍
- 若任务无任何可判定对错的题目：正确度维度不输出分值，报告注明原因，禁止以低权重补偿或猜测替代

## Reason

- 客观题对照教师答案判定：结果可解释、可追溯、家长可复核，误判风险最低
- 主观题不判对错：避免以"AI 好恶"判定开放性题而引发不信任
- 参考缺失/整卷主观时"不判定并明示"，贯彻 ADR-003 的"不武断"原则

## Consequences

- M001 创建任务时需提供题目录入界面（含学科/题型/可选参考答案）
- M005 评分引擎须支持"分题判定 + 加权聚合 + 不可判定降权/剔除"的配置化规则
- M007 报告在正确度不适用时展示说明文案，防止对分值的误读
- REQ-005 权重表在主观题占比高的任务上按规则重算，权重版本进入 DATA-006/010
