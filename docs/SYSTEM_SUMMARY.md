## 系统目标

V1 = **AI 每日作业智能评定系统**：让真实用户完成一次完整作业评价。
评分只代表「今日作业完成质量」，不是「学习能力评分」。详细见 `PROJECT.md`。

## 核心领域（Domain）

V1 规模较小，暂不建 Domain 层（按 `INDEX.md`，规模扩大时再引入）。业务域即"作业评定"：**V1 由 M001 + M002 + 横切 `app/core/ai/` 覆盖**（M003~M007 登记保留、状态 Deferred，`ADR-014`）。

## 模块关系

依赖方向（禁止环）：

```text
M002 → M001         （采集时读取任务 + 聚合上下文）
M001 / M002 → app/core/ai/ （横切基础设施；执行方 = AGENT-AI / Task-006）
—— 以下不属 V1（ADR-014）——
M005 → M001, M002   （评分需聚合子任务级结论）【V2，承 M002】
M006 → M005         （教师评价基于质量评价）【V2】
M007 → M001, M002, M005, M006（报告聚合）【V2】
```

无环。每个模块只经 API/DTO/Event/Contract 协作，不依赖内部实现。

## 主要数据流

```text
「任务」上传输入源(M001) ──► AI 解析草稿(链路 T) ──► 家长确认 ──► 按天任务记录
「作业」上传照片(M002) ──► 归属日/周次固化 ──► 聚合生成 ──► AI 挂接建议(链路 H)
    ──► 逐张复核 ──► 窗口级门控 ──► 聚合子任务级完成结论(草稿) ──► 家长确认  【V1 链路终点】
    ──►【V2】六维评分(M005) ──► 教师评价(M006) ──► 今日报告(M007，按聚合/周次)
              ▲             ▲                ▲
              └── 全链路可追溯记录（输入源/图片 → prompt 版本 → AI 输出 → schema 校验 → 规则 → 结论）
```

实体级数据见 `DATA_MODEL.md`。

## 主要业务流

- **家庭账号（家长）**布置作业任务（ADR-005 纯家庭模式，对应需求语境"教师"）→ 为家庭内**学生档案**上传作业照片 → 系统依次执行 **解析（链路 T）→ 挂接复核（链路 H）→ 聚合子任务级完成结论**（**V1 终点**；评分→教师评价→报告为 **V2**，`ADR-014`）
- AI 无法可靠判断时：不猜，允许"无法判断"，进入人工确认或提示重新拍摄
- 重写判断分级：无需重写 / 建议订正 / 建议重写部分题目 / 建议重新完成本项作业

## 关键技术决策

- ADR-001：采用文档驱动 + 总控 Agent 多 Agent 协作治理体系
- ADR-002：V1 范围控制（禁止提前开发未来功能；模块数量口径由 **`ADR-014`** 收窄为 M001 + M002 + 横切 `app/core/ai/`，M003~M007 保留登记、状态 Deferred）
- ADR-003：AI 评价边界与原则（可观察行为 / 不武断 / 配置化权重 / 分级重写 / 允许"无法判断"）
- ADR-004：技术栈 = 移动优先 H5 + Python FastAPI + SQLite 单体（PD-003 已确认）
- ADR-005：身份模型 = 纯家庭模式（家庭账号 + 学生档案，PD-004 已确认）
- ADR-006：正确度判定 = 分科混合策略（客观题对照参考答案 / 主观题不判对错并注明，PD-005 已确认）【**v0.9.0：已 Superseded → ADR-010**（内容级主客观全判 + 端到端直判），待 ACR-002 批准生效】
- ADR-007：AI Provider = 抽象 + Mock 先行（本地无 key 跑通全链路，PD-006 已确认）【**v0.9.0：已 Superseded → ADR-011**（真实三方默认、Mock 降级测试桩/离线），ACR-002 已批准（2026-09-08），正式生效】
- ADR-010：内容级判定 = 分科混合 + 主客观全判 + 端到端直判【**2026-09-10：判定粒度 Superseded → ADR-013**；端到端直判 / 可观察依据 / 置信度 / `无法判断` 出口 / 家长复核 / 不武断（ADR-003）原则由 ADR-013 继承】
- **ADR-013（Accepted，2026-09-10）**：作业任务语义重构 + **归属与判定双层模型**（事实层按天 + 聚合层跨天；**挂接与判定落聚合层**；判定粒度 = **聚合子任务（学科）级**；`task_items` 逐题建模废弃）→ 立项 **CHANGE-003（Executing）**
- PD-007/008：默认假设见 ASM-010/011，待用户复核
