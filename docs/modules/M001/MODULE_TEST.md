## 测试清单（对应验收断言）

- [ ] 注册：成功 201；重复 login_name 409；弱密码 422
- [ ] 登录：成功返回 token；错凭据 401；登出后原 token 401
- [ ] 学校字典：GET /schools 登录后 200（stage/keyword 过滤正确）；未登录 401；无写路径（POST/PATCH/DELETE /schools → 405）；seed 幂等
- [ ] 学生档案：创建/列表/更新；`school_id` 缺失或不存在 → 422；跨家庭 student_id → 403/404
- [ ] 任务创建：合法样例 201（draft）；题目集非法（空/seq 重复/主观题带答案）→ 422
- [ ] 任务查询：列表分页倒序；详情 `include_answers` 归属校验
- [ ] 状态机：draft→publish→(mark_in_progress 幂等)→close→reopen→close 全路径成功；非法边 409（如 draft→close）
- [ ] 冻结：in_progress/closed 下 update_task → 409；published 下可改标题但题目改动按规则校验
- [ ] 越权矩阵：未认证/异家庭/不存在三种情形响应语义正确（404 不泄露存在性）
- [ ] 事务：题目批量写中途失败 → 任务与题目均不存在
- [ ] 日志审计：登录取证、任务创建/状态变更有审计记录；日志不含密码/token/参考答案
