# 2026-09-11 工作记忆

## 内部服务器报错 — 排查与修复（用户报告「内部服务器在报错」）

- **现象**：用户反映内部服务器（FastAPI/uvicorn）在报错。
- **根因（实测）**：端口 **8010 上同时跑着两个 `uvicorn app.main:app --reload` 实例在抢端口**：
  - PID `39096` = `C:\Users\Administrator\AppData\Local\Programs\Python\Python312\python.exe`（**系统 Python，非项目 venv**）`--port 8010`，**未带 `AT_DATABASE_URL`** → 用默认库 `backend/data/app.db`（与种子库 `acceptance.db` 不同）。
  - PID `38164` = `backend/.venv/Scripts/python.exe`（项目 venv）同样 `--port 8010`（绑定必然失败）。
  - 实际持有 8010 的是系统 Python 那个；venv 那个绑定失败持续报错，且两套环境变量/库不一致 → 用户侧表现为「服务器报错 / 数据不对」。
- **诊断步骤**：① `netstat -ano` + `tasklist` 定位双实例；② 探活：GET `/`、`/docs`、`/openapi.json` = 200，`/api/v1/schools` 无 token = 401（正常），`/api/v1/family/login`(acceptance/acceptance123) = 401（说明活服务用的是 app.db，无种子账号），`/api/v1/family/register` = 201 → **API 读/认证路径本身健康，无 500**；③ 杀双实例后起重单一服务，登录后遍历 schools/students/tasks/task-groups/photos/photo-gates 等**全部 200**，`/completion-analyses`、`/me` 仅 404（未实现路由，非报错）；服务日志**无任何 traceback**。
- **修复**：`Stop-Process` 杀掉 `39096`/`39820`(子)/`38164` → 8010 释放；`& backend/.venv/Scripts/python.exe .e2e/seed.py`（重建 `acceptance.db`，`SEED_OK`）；起重**单一**服务 = venv + `AT_DATABASE_URL='sqlite:///./data/acceptance.db'` + `AT_FRONTEND_DIR='<root>/frontend/dist'` + `--port 8010 --log-level info`（无 `--reload`，日志 `at_server.log`/`at_server.err.log`）；现 8010 仅 PID `8200`(worker)/`34600`(父) 监听，运行正常。`.gitignore` 追加 `at_server*.log`。
- **结论**：应用本身无 Bug；报错源于**同端口双 uvicorn + 系统 Python 缺项目环境/库**。用户此前正式验收（237/0、浏览器级 18/18）已证明代码正确。
- **正确启动方式（防复发）**：务必用 `backend/.venv/Scripts/python.exe`；单实例；设 `AT_DATABASE_URL` 与 `AT_FRONTEND_DIR`；**同端口勿起多个 `--reload`**；起之前先 `netstat -ano | findstr ":8010"` 确认端口空闲。
- 排障注意：本机 shell 对复杂 PowerShell 命令偶发路由到 cmd 报错（`'Get-NetTCPConnection' 不是内部或外部命令`），改用 `cd` 前缀的 PowerShell 或原生 `netstat`/`tasklist` 更稳。

## 一键启动脚本（2026-09-11，用户要求）

- 新增 `start_server.ps1`（主脚本，全英文输出防 PS5.1 无 BOM 中文乱码）+ `start_server.bat`（双击入口：`powershell -NoProfile -ExecutionPolicy Bypass -File`）。
- 能力：自动清理同端口旧 uvicorn（仅认命令行含 `uvicorn`+`app.main` 的 python，绝不误杀其它进程）+ 清理孤儿 reloader；强制项目 venv（`backend/.venv/Scripts/python.exe`）；设 `AT_DATABASE_URL=sqlite:///./data/{Db}.db` + `AT_FRONTEND_DIR`；单实例；启动后轮询端口 + `GET /` 健康自检。
- 用法：`.\start_server.ps1`（默认 8010 + acceptance.db）/ `-Db app` / `-Seed`（重建种子库）/ `-Reload`（开发热重载）/ `-Port N` / `-Stop`。
- 已实测：自动清旧实例(8200)→起新实例→Health 200；`-Stop` 停净端口；重起后 8010 单监听(PID 9884)。git 仅新增 2 个脚本（`?? start_server.bat/ps1`），`at_server*.log` 已被 gitignore 忽略。
